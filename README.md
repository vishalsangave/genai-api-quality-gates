# DriftGate

DriftGate is an open-source API testing framework for non-deterministic GenAI microservices. It combines deterministic OpenAPI/JSON Schema validation, AST-aware cassette replay, streaming SSE telemetry, metamorphic checks, and a statistical PROMOTE / HOLD / ROLLBACK release governor.

> This repository is under active development. Complete installation, quick-start guidance, architecture, references, and CI instructions will be added with the runnable demo and validation suites.
